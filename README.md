# Portfólio Técnico — Gabriel Chaves (`gccavalcante`)

🔗 **Site em Produção:** [https://gabrielchavesdev.vercel.app](https://gabrielchavesdev.vercel.app)

Portfólio profissional focado em **Engenharia de Software (Back-end & Full-Stack)** e **Análise de Dados / Business Intelligence (SQL, Python, Power BI)**.

## Estrutura do Projeto
- `index.html`: Estrutura semântica com **WebGL2 Glass Light Toggle** na barra superior, **Seletor de Lente Técnica** (Visão Completa / Back-end / Dados & BI), estudos de caso com inspeção de arquitetura e schema SQL, e matriz de formação em Dados.
- `styles.css`: Tokens CSS para o tema padrão **Dark Terminal (Opção 3)** e **Editorial Claro (Opção 1)**, crossfade óptico entre as fontes `Plus Jakarta Sans` e `Syne`, e opção 2 (`blueprint`) preservada.
- `app.js`: Shader WebGL2 de refração óptica, dispersão cromática, barra de LED orbitante e física de mola por pixel (Lua ⇄ Sol).
- `curriculo-gabriel-chaves.pdf`: Currículo oficial para download direto.
- `opcoes-salvas/`: Arquivos independentes das 3 direções visuais (`opcao-1-editorial.css`, `opcao-2-blueprint.css`, `opcao-3-terminal.css`).
- `DESIGN.md`: Documento de decisões de design e tokens do projeto.
- `vercel.json`: Configuração para publicação na Vercel.
