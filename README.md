# Portfólio Técnico — Gabriel Chaves (`gccavalcante`)

Portfólio profissional focado em **Engenharia de Software (Back-end & Full-Stack)** e **Análise de Dados / Business Intelligence (SQL, Python, Power BI)**.

## Estrutura do Projeto
- `index.html`: Estrutura semântica com **Seletor de Lente Técnica** (Visão Completa / Back-end / Dados & BI), estudos de caso com inspeção de arquitetura e schema SQL, matriz de formação em Dados e comparador de 3 direções visuais.
- `styles.css`: Tokens CSS para as 3 direções (`editorial`, `blueprint`, `terminal`), escala tipográfica 1.25 e grade responsiva.
- `app.js`: Alternância de direção visual, filtragem por lente de vaga e abas de inspeção técnica.
- `curriculo-gabriel-chaves.pdf`: Currículo oficial para download direto.
- `DESIGN.md`: Documento de decisões de design e tokens do projeto.
- `vercel.json`: Configuração limpa para publicação imediata na Vercel.

## Como publicar no GitHub + Vercel
1. Inicialize o repositório Git ou suba os arquivos para um repositório no seu GitHub (`github.com/gccavalcante`).
2. No painel da [Vercel](https://vercel.com), clique em **Add New Project** e selecione o repositório.
3. Mantenha **Framework Preset: Other** e clique em **Deploy**.
