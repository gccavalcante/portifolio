# Opções de Direção Visual Salvas

As três direções visuais criadas durante o processo de design estão preservadas nesta pasta e no `styles.css`:

1. **`opcao-1-editorial.css` (`data-direction="editorial"`):** Tema Claro ativo por padrão no toggle (Sol).
2. **`opcao-3-terminal.css` (`data-direction="terminal"`):** Tema Escuro ativo no toggle (Lua).
3. **`opcao-2-blueprint.css` (`data-direction="blueprint"`):** Papel Técnico & Blueprint de Dados (Esmeralda). Para ativá-la a qualquer momento, basta passar `?dir=blueprint` na URL ou definir `data-direction="blueprint"` na tag `<html>` em `index.html`.
